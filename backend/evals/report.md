## Reading the numbers

- **budget / outcome**: the baseline never retries cheaper options and never warns, so tight and impossible budgets end over budget with no warning.
- **rain**: the baseline ignores weather; the graph swaps outdoor stops for indoor ones on rainy days.
- **outcome on blocked prompts**: the baseline has no guardrail, so injection and card-number prompts are processed instead of refused.
- Parsing (`constraints`) is the same rule-based code in both, so it should match.
